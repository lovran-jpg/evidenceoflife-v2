## Capture tips

1. Use the synthetic demo so no real personal data appears: `/demo-app`
2. Prefer 1440×900 (or similar) desktop viewport
3. Dark mode is the primary surface — capture that by default
4. Keep filenames lowercase with hyphens

`demo-preview.png` is already checked in from the public demo.
