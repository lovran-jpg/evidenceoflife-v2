01

The Unifying Metaphor

Daily Retrospective

你是自己生活的 artist-in-residence，每天策划一场新的展览。

App 不是被动的日记，而是你的个人美术馆。记录不再是“我今天做完了什么”，而是“今天有哪些生活证据值得被挂上墙”。这把 logging 从负担（必须记）变成创作（值得策展）。三个机构化的动词贯穿全局：

Accession

入藏

每条 moment 被“登记入馆”，获得编号与媒材描述，从瞬间变成藏品。

Wall Label

展签

记录以美术馆墙签的方式呈现：小、准、权威、安静——而不是花哨卡片。

Curation

策展

每天/每周从记录中挑出值得入藏的几件，赋予意义，而非堆砌数据。

Typography System

Two faces, strict roles

Display — Archivo / Archivo Narrow. 替代 Franklin Gothic Condensed 的开源选择：bold、condensed、neo-grotesque。只出现在“制度化命名”的地方，且全大写。

Label / Body — Inter. 中性 grotesk，承载所有信息层。刻意不走“温柔文艺 serif”——那会把产品推向 lifestyle 杂志，而非现代美术馆。

Anatomy — 5 fixed lines

1 · Title — 用户写的标题，最强视觉层（18px）。
2 · Maker / Time — You, 2026，次级灰白斜体。
3 · Medium — 媒材：walk / note / voice / dinner…让普通生活获得“可归档性”。
4 · Context — 地点 · 时长 · 同伴。
5 · Accession № — EOL.2026.06.26.014 不是噱头，它让“证据”变成“藏品”。

它是 placard，不是 card：无背景色、无边框、无阴影，纯粹靠 typography 与留白挂在墙上。

Where it appears

完整展签 → Recap；关键 moment 展开 → Today；点击地点弹出 → Map。
克制：Plan timeline 只借标题 + 微型 metadata（它仍是时间工具，不能被 museum 化拖慢）；Dues 不套展签——deadline 不是作品。

05

Color Reconciliation

Warm base · B&W structure · Bauhaus punctuation

关键纪律：直接把 MoMA 理解成“黑白红蓝黄铺满”，只会做成廉价的学生 Bauhaus poster。三方各司其职——

The Gallery — base
EOL 暖暗色基底不丢。深炭黑带一点土灰暖墨感，不用纯黑。承载所有阅读面。
Structure — B&W
黑白只负责 typographic authority：大标题、关键分隔线、高对比 label。留白靠 spacing，不靠把整页刷白。
The Artwork — warm
Terracotta = human warmth；gray-green = ambient system。timeline 时间块保持原样，它们就是挂在墙上的“画”。
Bauhaus — punctuation only
红=memory intensity，蓝=place/movement，黄=reflection/note。只做小标记、选中点、pin ring、locator bar。

守住 low-saturation 时间块铁律：MoMA primaries 进入 timeline 的唯一方式是 annotation（左侧 2px status rail / 当前时间指针 / legend 小色点 / 完成态小角标），绝不是 fill。时间块继续低饱和实色填充（≤46）。

06

Motion

The stillness of the gallery

动效像 gallery lighting 的变化，不像 startup app 的弹跳。Restrained · linear · intentional。

01Page enter — 轻微 stagger，40–80ms 差，位移 ≤ 8–12px。无大面积 parallax。
02Wall label — 淡入 + 微上移，120–160ms。
03Hover — 不做 scale / shadow；只做对比增强、边界浮现、信息展开（像策展人的 laser pointer）。
04Year hover — 相邻单元轻退后，像墙上 spotlight 转移。
05Respect prefers-reduced-motion — 全部降级为纯 opacity。
07

Signature Feature

The one bold move
Daily · after 21:00
Curator's Cut

每天系统自动从所有记录里挑出 3 件“值得入藏”的作品，组成一张小型展签页。它不是“AI 总结”，是 curatorial selection——每件附一条极短的策展短评，把普通日常翻译成意义。

Emotion / relation
Dinner with Lin
“An ordinary dinner becomes evidence of continuity.”
Time / focus
75 min, no phone
“The afternoon read as deep work, not busyness.”
Body / space
Walk by the river
“Transit time here reads as recovery, not waste.”

⚠︎ 刻意反对“一键生成今日展览海报”——太社交媒体、太一次性、太 gimmick。Curator's Cut 更安静，但改变用户如何理解自己记录下来的生活。

Implementation Roadmap

Mapped to real files
01

Typography foundation small

  • 引入 Archivo / Archivo Narrow + Inter，定义 display / narrow / body 三个 family token
  • 在 tailwind.config.ts 加 fontFamily.display + 模块化 type scale
  • 先只改 view 顶部标题（TODAY / RECAP / YEAR）验证方向，不动正文
02

Wall-label component medium

  • 新建 WallLabel.tsx：5 行结构 + accession 编号生成器（lib/ 纯函数）
  • 在 Recap 与点击 timeline 块的详情里渲染（复用现有 moment 数据，无需改 DB）
  • placard 样式：无背景 / 无边框，纯 typography + spacing
03

Color roles into tokens small

  • 在 styles/tokens.css 加 --bauhaus-red/blue/yellow（仅 annotation 用）
  • 把 gallery base 深炭黑微调到带暖墨感；保持 timeline 低饱和铁律不变
  • timeline 块加可选 2px status-rail，颜色取自 Bauhaus primary（annotation，非 fill）
04

Salon Recap + Accession Year large

  • Recap 改 asymmetric salon grid（preface 窄栏 + selected 主区 + contact sheet）
  • Year 视图加月份呼吸带 + 每月策展短评；保留 year-in-pixels 密度
  • gallery 式 motion + prefers-reduced-motion 降级
05

Curator's Cut large

  • 每日 selection 逻辑：emotion / time / body 三类各选 1（先规则，后可接模型）
  • 策展短评生成 + 落入 Recap 作为当天定稿条目
  • 21:00 后的入口提示（复用 useLifeReminder 体系）
最后一句设计判断
不要把 EOL 做成像 MoMA 的 app；要把 EOL 做成「你的生活被 MoMA 式地认真对待」。
